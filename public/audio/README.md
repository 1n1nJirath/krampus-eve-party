# Krampus Eve BGM Audio Files

Place your 4 background music MP3 files in this directory (`public/audio/`):

1. `bgm-lounge.mp3`
   - **Where it plays:** Lobby, World Map, Briefing/Rules, and Standby moments.
   - **Vibe:** Atmospheric Christmas Manor, eerie cozy lounge, mysterious music box or acoustic guitar.

2. `bgm-suspense.mp3`
   - **Where it plays:** Active questions, thinking time, trivia solving.
   - **Vibe:** Low-pulsing heartbeat, ticking tension, mysterious dark ambient.

3. `bgm-panic.mp3`
   - **Where it plays:** 10 seconds countdown, Fast Finger speed-lock, Krampus 25-step escape chase.
   - **Vibe:** Fast-paced adrenaline rush, intense drums, sirens/chase music.

4. `bgm-victory.mp3`
   - **Where it plays:** Finale ceremony, champion reveal, victory celebration.
   - **Vibe:** Triumphant holiday fanfare, heroic bells, celebratory victory theme.

*Note: If any MP3 file is not yet provided, the game automatically uses the built-in Web Audio atmospheric drone fallback so the app will never crash or silence.*
